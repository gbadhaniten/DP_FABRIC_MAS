Token reduction tips
  • Route via run_fabric_agent not execute_fabric_task — saves ~40% prompt tokens by bypassing keyword planner reasoning
  • Use plan_from_json() — feed pre-built JSON plan, Copilot skips intent classification
  • Trim examples.md to 5 most recent — large history bloats agent knowledge load
  • Enable FABRIC_DRY_RUN=false — dry-run outputs verbose previews that consume tokens
  • Disable unused MCP tools in mcp.json — each tool description occupies ~80 tokens
  • Use official Fabric MCP server (microsoft/mcp) for schema lookups instead of search_fabric_docs
  • Set max_examples=3 in BaseAgent.load_knowledge() to cap few-shot examples
